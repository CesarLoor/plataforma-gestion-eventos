# Plataforma de gestión de eventos

Plataforma web (PWA) para publicar eventos locales, reservar y vender entradas sin sobreventa, emitir tickets con QR firmado y controlar el ingreso, incluso sin conexión. Microservicios coordinados por eventos, desplegados con Docker en un solo servidor.

Proyecto de la asignatura **Construcción y evolución del software** (NRC 36847), Carrera de Ingeniería de Software, ESPE.
